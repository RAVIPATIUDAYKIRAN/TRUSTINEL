# Sprint 2 Walkthrough (Backend Core & Flow Verification)

We have successfully completed Sprint 2 for **TRUSTINEL**. All task goals have been realized, establishing a robust database and backend pipeline using Clean Architecture.

## Summary of Changes

### Database Layer
- [x] Implemented SQLAlchemy declarative mapping models: `WebsiteScan`, `TrustReport`, and `ScanHistory` in `app/models/`.
- [x] Defined type-safe enums: `ScanStatus` and `RiskLevel` in `app/models/enums.py`.
- [x] Configured Alembic to load the Declarative Base metadata and autogenerated the initial migration script.
- [x] Applied migrations to map PostgreSQL tables.

### Pydantic Validation Schemas
- [x] Implemented Pydantic v2 schemas: `ScanCreateRequest` (validating http/https URLs using `HttpUrl`), `ScanResponse`, `TrustReportResponse`, and `ErrorResponse` inside `app/schemas/`.

### Business & Repository Layers
- [x] Implemented generic `BaseRepository` and domain repositories: `WebsiteScanRepository`, `TrustReportRepository`, and `ScanHistoryRepository` in `app/repositories/`.
- [x] Implemented `MockTrustReportGenerator` generating deterministic ratings based on normalized URL SHA-256 hashes.
- [x] Implemented `ScanService` orchestrating the database transactional logic (inserts, logs, updates, rollbacks, and commits).

### API Route Endpoints
- [x] Registered routes in `app/api/scan.py` and mounted them inside `app/main.py`:
  - `POST /api/v1/scan`: Triggers a new website scan.
  - `GET /api/v1/scan/{scan_id}`: Retrieves details of a scan and its trust report by UUID.
